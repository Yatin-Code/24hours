# Why one thing

Most tools I could have built in a day would have been a dashboard.
A dashboard of dashes: todos, habits, streaks, charts, badges, sync.

`hours` is the opposite. It shows you one deadline and one sentence.
It rings at 10/25/50/75/90/100% so a long run still feels alive,
and it shuts up about everything else.

Reasons:

1. Attention is not a resource you optimize. It is the thing you spend.
   A tool that asks for "more focus" is asking you to be a machine.
   A tool that keeps one task in front of you and waits is a friend.
2. Dependencies are a form of trust. Every `pip install` is an apology.
   Zero dependencies: zero apologies, zero supply-chain surprises.
3. Honesty is a feature. The README lists what's broken before you find it.
